# tiny-bot-easy-entry

Long-only EMA(5)/EMA(13) crossover paper-trading bot for the make.fun bounty "Tiny Bot, Easy $2: Beat Buy-and-Hold on Solana" (u-gorun-gadget-tiny-bot-easy-2-beat-a48f3ce1). Trades FARTCOIN, JITOSOL, POPCAT, RAY, SOL, WETH and WIF on 1h bars with one rule set for every symbol — no per-symbol tuning, no hard-coded prices or dates, no network, no clock, no randomness: two runs produce byte-identical action logs.
